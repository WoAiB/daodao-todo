# 叨叨清单 · Daodao List

一个**纯本地**运行的网页版「日程 + 待办 + 习惯打卡」小工具。

你负责「叨叨」一句，它负责帮你整理成任务、排进日历、督促打卡、发奖章。可爱、清亮、动漫插画风。

> 不注册、不登录、不联网部署、不做账号体系。你的所有数据只存在你自己电脑的浏览器里。

---

## 一、这是什么

一句话：**「你负责叨叨，它负责整理、督促和发奖」的私人日程管家。**

主要功能：

| 功能 | 说明 |
|---|---|
| 🎤 语音/文字输入 | 说一句话，自动拆成任务 / 日程 / 习惯 |
| ✅ 今日 To Do | 当天的任务 + 自动合并的习惯打卡 + 顺延任务 |
| 🗓 本周待办 + 周日历 | 一屏看到「今天做什么 / 这周有什么 / 时间在哪儿」，类别按颜色区分 |
| 🔁 习惯打卡 | 设置「每周一三五健身」等，每天自动生成打卡项 |
| 🏅 奖章系统 | 连续全勤 / 清空清单得奖章，攒奖章换奖励 |
| ⏰ 桌面提醒 | 每晚提醒还没完成的事（需要浏览器通知权限） |
| 🐣 吉祥物「叨叨」 | 打卡变精神、不打卡就蔫掉的可爱团子 |

## 二、怎么跑起来（零基础版）

这是纯网页项目，**没有安装包**，跑起来只需要一台装了 **Python** 的电脑（大多数情况已经装好了）。

### 方法 A：双击启动（Windows，最简单）

1. 双击项目里的 **`启动叨叨清单.bat`**；
2. 浏览器会自动打开 `http://localhost:8417`，就能用了。

> 如果双击后一闪而过 / 提示 `python` 不是命令，说明电脑还没装 Python，看方法 B。

### 方法 B：没装 Python？先装一下

1. 打开 <https://www.python.org/downloads/>，下载最新版 Python；
2. 安装时**务必勾选** `Add python.exe to PATH`（中文版：`将 Python 添加到 PATH`）；
3. 装完后，再回到方法 A 双击 `.bat` 即可。

### 方法 C：用 VS Code 的 Live Server

1. 安装 [VS Code](https://code.visualstudio.com/)；
2. 装扩展「Live Server」；
3. 用 VS Code 打开本项目文件夹，右键 `index.html` → `Open with Live Server`。

> ⚠️ 注意：**不能直接双击 `index.html`**（会用 `file://` 打开），因为浏览器安全限制会导致页面打不开。必须通过上面的本地服务器访问。

## 三、数据与隐私（重要）

- **全部数据存在本机浏览器 IndexedDB**，不上传任何服务器、不登录；
- **语音识别**用的是浏览器自带的 Web Speech 接口（可能需要联网，语音可能发到浏览器厂商的识别服务）；
- **AI 解析兜底（可选）**：只有当你说的那句话「本地规则解析不了」时，才会把这句话的文本发给阿里云百炼（通义千问）解析；**默认没配 Key，不会发任何东西**。想开启请看下一节。

---

## 四、想开启「AI 解析兜底」？（可选，需要自己的 Key）

不开也不影响基本使用（本地规则已经能处理绝大多数说法）。想让它更「聪明」的话：

1. 打开 [阿里云百炼 DashScope](https://dashscope.aliyun.com/)，注册并开通「模型服务」；
2. 申请一个 API Key（形如 `sk-xxxx`）；
3. 打开应用右上角 **⚙ 设置 → AI 解析兜底**：
   - 勾选「启用」；
   - 把 Key 粘贴进「API Key」输入框；
4. 关闭设置即可，Key 存在你本机，**不会进入 GitHub**。

> 更省事的本地固化方式：把项目里的 `config.local.example.js` 复制一份改名为 `config.local.js`，在里面填上你的 Key（这个文件已被 git 忽略，不会上传）。

## 六、项目结构（给开发者）

```
叨叨清单/
├─ index.html                 # 主界面（HTML + 全部 CSS）
├─ 启动叨叨清单.bat            # Windows 一键启动（python http.server）
├─ PRD-叨叨清单-个人日程待办工具.md   # 产品需求文档（规则/奖章/布局）
├─ 叨叨清单-主界面视觉稿.pdf        # 视觉设计稿
├─ config.local.example.js    # 本地个性化配置模板（复制成 config.local.js 生效，已被 gitignore）
└─ js/
   ├─ main.js                 # 入口：初始化 + 所有 UI 交互
   ├─ db.js                   # IndexedDB 数据层
   ├─ store.js                # 设置访问层 / 旧数据迁移
   ├─ seed.js                 # 首启预置数据（类别/习惯/奖章/默认设置）
   ├─ parse.js                # 中文自然语言规则解析（本地、零延迟）
   ├─ llm.js                  # 通义千问 AI 解析兜底（可选）
   ├─ render.js               # 渲染层（今日/本周/日历/月视图）
   ├─ badges.js               # 奖章引擎
   ├─ util.js                 # 日期等工具函数
   └─ annotate.js             # 页面标注模式（给设计提意见用）
```
